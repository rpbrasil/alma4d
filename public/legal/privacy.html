Política de Privacidade

Esta Política de Privacidade descreve como o aplicativo alma4D coleta, utiliza, armazena e protege os dados pessoais de seus usuários.

📥 Coleta de Dados

  • Número de telefone, utilizado exclusivamente para autenticação via código de uso único (OTP)
  • Dados básicos de uso e navegação no aplicativo
  • Informações fornecidas voluntariamente pelo usuário durante o uso do aplicativo

O número de telefone não é utilizado para marketing, publicidade, contato comercial ou envio de comunicações promocionais.

🧠 Uso dos Dados

  • Autenticação segura de usuários
  • Funcionamento e melhoria contínua do aplicativo
  • Análises operacionais e de desempenho
  • Segurança e prevenção contra fraudes

O aplicativo não utiliza dados pessoais para fins discriminatórios, abusivos ou ilícitos.

🔔 Notificações

  • Lembretes configurados pelo próprio usuário
  • Atualizações e novidades relevantes do aplicativo
  • Mensagens importantes relacionadas ao uso do serviço

O usuário pode gerenciar ou desativar as notificações a qualquer momento nas configurações do sistema operacional do dispositivo.

🤝 Compartilhamento de Dados

Os dados pessoais podem ser compartilhados exclusivamente com provedores de tecnologia essenciais ao funcionamento do aplicativo, incluindo:

  • Firebase (Google LLC) – serviços de infraestrutura, segurança e notificações
  • Supabase – autenticação de usuários e armazenamento de dados

Esses parceiros tratam os dados de acordo com suas próprias políticas de privacidade e padrões de segurança. O alma4D não vende dados pessoais a terceiros.

🔒 Armazenamento e Segurança

Adotamos medidas técnicas e administrativas adequadas para proteger os dados pessoais contra acessos não autorizados, perda, uso indevido ou divulgação indevida.

📅 Retenção de Dados

Os dados pessoais são armazenados apenas pelo tempo necessário para cumprir as finalidades descritas nesta política, respeitando obrigações legais e regulatórias.

🧾 Direitos do Usuário

O usuário pode, a qualquer momento, solicitar acesso, correção ou exclusão de seus dados pessoais, bem como revogar consentimentos concedidos, quando aplicável.
