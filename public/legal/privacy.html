Política de Privacidade — alma4D

Última atualização: Abril de 2026

Esta Política de Privacidade descreve como o aplicativo alma4D coleta, utiliza, armazena e protege os dados pessoais de seus usuários, em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD — Lei nº 13.709/2018).

1. Controlador e Contato

O aplicativo alma4D é operado pelo controlador responsável pelo tratamento de dados pessoais.

Contato para assuntos de privacidade:
cliente@voss.digital

2. Coleta de Dados

2.1 Dados fornecidos pelo usuário

  • Número de telefone
  • Dados inseridos voluntariamente
  • Preferências e configurações

O número de telefone é utilizado exclusivamente para autenticação via código OTP, segurança e gerenciamento de acesso. Não é usado para marketing.

2.2 Dados coletados automaticamente

  • Endereço IP
  • Tipo e modelo do dispositivo
  • Sistema operacional
  • Logs de acesso
  • Tempo de uso
  • Dados de desempenho e falhas

2.3 Dados sensíveis

O alma4D não solicita intencionalmente dados sensíveis, salvo quando estritamente necessários e mediante consentimento adequado.

3. Uso dos Dados

  • Autenticação e segurança
  • Prevenção à fraude
  • Funcionamento do aplicativo
  • Melhoria da experiência do usuário
  • Correção de falhas e análises técnicas
  • Cumprimento de obrigações legais

4. Base Legal

  • Consentimento
  • Execução contratual
  • Obrigação legal
  • Legítimo interesse
  • Segurança e prevenção à fraude

5. Notificações

  • Lembretes configurados pelo usuário
  • Informações relevantes sobre o serviço
  • Alertas técnicos e de segurança

6. Compartilhamento de Dados

Os dados podem ser compartilhados exclusivamente para a operação do serviço:

  • Firebase (Google LLC)
  • Supabase
  • Autoridades públicas, quando exigido por lei

O alma4D não vende dados pessoais.

7. Armazenamento e Segurança

Os dados são armazenados em ambientes protegidos com controles de acesso, criptografia e monitoramento.

8. Retenção de Dados

Os dados são armazenados apenas pelo tempo necessário ao cumprimento das finalidades, obrigações legais e segurança.

9. Direitos do Usuário

  • Acesso
  • Correção
  • Exclusão
  • Portabilidade
  • Revogação do consentimento

Solicitações devem ser feitas via:
cliente@voss.digital

10. Exclusão de Dados

O usuário pode solicitar a exclusão definitiva de seus dados, respeitando obrigações legais e regulatórias.
